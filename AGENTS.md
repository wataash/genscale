# genscale

genscale is a Next.js app for visualizing scale and chord-tone labels on a guitar fretboard and exporting the result as SVG.

## Development

```bash
pnpm dev
```

Open <http://localhost:3000> in a browser.

## Verification

```bash
pnpm lint
pnpm build
pnpm exec playwright test
```
