# Guitar Scale Board 仕様

## 概要

Guitar Scale Board は、ギター指板上にスケールやコードトーンを可視化するWebアプリです。キーとスケールプリセットを選ぶと、標準チューニングの0から24フレットに各音の機能名を表示します。表示中の指板はSVGとして書き出せます。

## 主な機能

- キー選択
- スケールプリセット選択
- 異名同音のキー対応
- 12音ラベルのカスタム編集
- 強調音と非強調音の描き分け
- 24フレット指板のSVG描画
- 表示中SVGのダウンロード

## 画面構成

アプリは単一画面です。

- 左側の操作パネルでキー、スケール、カスタムラベルを編集します。
- 右側のプレビュー領域に指板SVGを表示します。
- ヘッダーの「SVGを書き出し」ボタンで現在の表示を保存します。

## キー

キーは半音単位で扱います。内部の基準は `A = 0` で、以降 `A#`, `B`, `C` の順に11まで割り当てます。フラット表記や一部の異名同音も同じ音へ正規化します。

例:

- `Bb` は `A#`
- `Db` は `C#`
- `E#` は `F`
- `Cb` は `B`

## スケールプリセット

スケールプリセットは12個のラベルトークンで構成します。各トークンは、ルートからの半音オフセット順に並びます。

例:

```text
.1 ♭9 9 .♭3 3 11 ♯11 .5 ♭13 13 .♭7 Δ7
```

現在のアプリには、メジャー、マイナー、ドミナント、ディミニッシュ、ペンタトニック、オルタードなどのプリセットがあります。

## カスタムラベル

「12音ラベルを編集」を有効にすると、Notesテキストエリアでラベルを直接編集できます。

入力ルール:

- 空白区切りで12個指定します。
- 並び順はルートからの半音オフセット順です。
- 先頭に `.` を付けたトークンは強調音として表示します。
- 表示時には先頭の `.` は取り除かれます。

12個以外の場合は、画面上に警告を表示し、指板は現在選択中のスケールプリセットで描画します。

## 指板

- チューニングは標準チューニング `E A D G B E` です。
- 表示範囲は0から24フレットです。
- 12フレットと24フレットは太いフレット線で表示します。
- 3/5/7/9/15/17/19/21フレットは単一インレイです。
- 12/24フレットは二重インレイです。

フレット位置は平均律の弦長比から計算します。

```text
L - L / 2^(n/12)
```

この値を0から24フレット表示用に正規化し、SVGのX座標へ変換します。

## SVG書き出し

画面上のSVG要素を文字列化し、Blob URLを使ってブラウザから保存します。ファイル名は現在のキーとスケール、またはカスタムモードに応じて決まります。

例:

- `A-m7.svg`
- `C-M7.svg`
- `E-custom.svg`

## 実装

アプリ本体は [app/page.tsx](/home/wsh/d/s/guitar_board/app/page.tsx) です。状態管理はReactの `useState`、指板の静的データ生成は `useMemo` を使います。サーバーAPIは使わず、すべてブラウザ内で描画します。

E2Eテストは [e2e/example.spec.ts](/home/wsh/d/s/guitar_board/e2e/example.spec.ts) にあります。
