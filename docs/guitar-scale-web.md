# genscale 仕様

## 概要

genscale は、ギター指板上にスケールやコードトーンを可視化するWebアプリです。キーとスケールプリセットを選ぶと、標準チューニングの0から24フレットに各音の機能名を表示します。表示中の指板はSVGとして書き出せます。

## 主な機能

- キー選択
- スケールプリセット選択
- 異名同音のキー対応
- 12音ラベルのカスタム編集
- スケール内音とスケール外音の描き分け
- 24フレット指板のSVG描画
- 表示中SVGのダウンロード

## 画面構成

アプリは単一画面です。

```text

+--------------------------------------------------------------+

+--------------------------------------------------------------+

+--------------------------------------------------------------+
| Key / Scale                                                  |
| [select box] [select box]                                    |
|                                                              |
| Tuning                                                       |
| +----------------------------------------------------------+ |
| | E4                                                       | |
| | B3                                                       | |
| | G3                                                       | |
| | D3                                                       | |
| | A2                                                       | |
| | E2                                                       | |
| +----------------------------------------------------------+ |
|                                                              |
| Notes                                                        |
| +----------------------------------------------------------+ |
| |                                                          | |
| | textarea                                                 | |
| |                                                          | |
| +----------------------------------------------------------+ |
|                                                              |
| Settings editor                                              |
| +----------------------------------------------------------+ |
| | {                                                        | |
```

- 上側のプレビュー領域に指板SVGを表示します。

- ヘッダーの「SVGを書き出し」ボタンで現在の表示を保存します。

## i18n

UIは英語と日本語に対応します。

- `/en`: 英語UI
- `/ja`: 日本語UI
- `/`: `/en` へリダイレクト

言語切り替えはヘッダー右側の `EN` / `JA` リンクで行います。

## キー

キーは半音単位で扱います。内部の基準は `A = 0` で、以降 `A#`, `B`, `C` の順に11まで割り当てます。フラット表記や一部の異名同音も同じ音へ正規化します。

例:

- `Bb` は `A#`
- `Db` は `C#`
- `E#` は `F`
- `Cb` は `B`

## スケールプリセット

スケールプリセットは12個のラベルトークンで構成します。各トークンは、ルートからの半音オフセット順に並びます。

例:

```text
1
_♭9
_9
♭3
_3
_11
_♯11
5
_♭13
_13
♭7
_Δ7
```

現在のアプリには、メジャー、マイナー、ドミナント、ディミニッシュ、ペンタトニック、オルタードなどのプリセットがあります。

画面上のスケール選択では `Altered` のような正式名を表示します。内部IDとSVGファイル名には `alt` などの短い識別子を使います。

## 設定エディタ

Settings editor には現在の設定をJSONで表示します。UI上のキー、スケール、チューニング、Notesを変更するとJSONも更新します。

JSONを編集すると、内容が有効な場合はUIにも反映します。`scale` には `m7` や `alt` などの内部IDを指定します。`tuning` と `notes` は行順と同じ配列で指定します。

## Notes

Notesテキストエリアで12音のラベルを直接編集できます。

入力ルール:

- 行区切りで12個指定します。
- 並び順はルートからの半音オフセット順です。
- 先頭に `_` を付けたトークンはスケール外音として表示します。
- 表示時には先頭の `_` は取り除かれます。
- `_` だけを指定した音は、丸だけを表示してラベル文字は表示しません。

ラベルを省略した例:

```text
1
_
_
♭3
_
_
_
5
_
_
♭7
_
```

12個以外の場合は、画面上に警告を表示し、指板は現在選択中のスケールプリセットで描画します。

## Interval 表記

Notesの各行は、ルートからの半音オフセットに対応します。ラベルとして使う interval 表記は自由文字列ですが、プリセットとドキュメントでは次の表記を使います。

| 半音 | 主な表記 |
| ---: | --- |
| 0 | `1`, `R`, `Root`, `P1` |
| 1 | `m2`, `♭2`, `b2`, `♭9`, `b9`, `♯1`, `#1`, `A1` |
| 2 | `M2`, `2`, `9`, `𝄫3`, `bb3` |
| 3 | `m3`, `♭3`, `b3`, `♯2`, `#2`, `♯9`, `#9` |
| 4 | `M3`, `3`, `10`, `♭4`, `b4` |
| 5 | `P4`, `4`, `11`, `♯3`, `#3` |
| 6 | `TT`, `tritone`, `♭5`, `b5`, `♯4`, `#4`, `♯11`, `#11` |
| 7 | `P5`, `5` |
| 8 | `m6`, `♭6`, `b6`, `♯5`, `#5`, `♭13`, `b13` |
| 9 | `M6`, `6`, `13`, `𝄫7`, `bb7` |
| 10 | `7`, `m7`, `♭7`, `b7`, `♯6`, `#6` |
| 11 | `M7`, `Δ7`, `maj7`, `♭8`, `b8` |

`♭` と `b`、`♯` と `#` は同じ意味の表記として扱えます。`Δ7` はメジャーセブンスを表します。

## 指板

- チューニングは1行1弦で指定します。上の行が指板の上側の弦です。
- 初期値は標準ギターチューニング `E4 B3 G3 D3 A2 E2` です。
- 行数を増減すると、表示する弦の数も変わります。
- 各行は `E4` や `Bb2` のように音名とオクターブで指定します。
- 表示範囲は0から24フレットです。
- 12フレットと24フレットは太いフレット線で表示します。
- 3/5/7/9/15/17/19/21フレットは単一インレイです。
- 12/24フレットは二重インレイです。

フレット位置は平均律の弦長比から計算します。

```text
L - L / 2^(n/12)
```

この値を0から24フレット表示用に正規化し、SVGのX座標へ変換します。

## SVG書き出し

画面上のSVG要素を文字列化し、Blob URLを使ってブラウザから保存します。ファイル名は現在のキーとスケール、またはカスタムモードに応じて決まります。

例:

- `A-m7.svg`
- `C-M7.svg`
