# genscale 仕様

## 概要

genscale は、ギター指板上にスケールやコードトーンを可視化するWebアプリです。edit ではキー、スケールプリセット、チューニングを編集して 0 から 24 フレットに各音の機能名を表示します。concat では `Copy URL with this settings (experimental)` で得た設定URLを複数行貼り付けて、指板を縦に並べて確認できます。concat の textarea には起動時からサンプルURLを 3 行入れておきます。edit の表示中の指板は SVG として書き出せます。

## 主な機能

- キー選択
- スケールプリセット選択
- 異名同音のキー対応
- 12音ラベルのカスタム編集
- NOTE色のグレースケール調整
- スケール内音とスケール外音の描き分け
- 24フレット指板のSVG描画
- 表示中SVGのダウンロード
- GitHubリポジトリへのリンク
- 現在の設定を含むURLのコピー
- edit/concat のタブ切り替え
- 複数設定URLの一括プレビュー

- edit では上側のプレビュー領域に指板SVGを表示し、下側の操作パネルでキー、スケール、Notes、NOTE色、チューニング、設定JSONを編集します。
- concat では textarea に 1 行 1 URL で設定URLを貼り付け、その下に有効な URL ごとの指板を表示します。
- concat の textarea には初期値として D m7 / G Altered / C Δ7 のサンプル設定URLを 3 行入れておきます。
- concat の各指板の上には `Line N: KEY SCALE` の見出しを表示します。日本語UIでは `N行目: KEY SCALE` です。
- ヘッダーの「SVGを書き出し」ボタンは edit でのみ表示し、現在の表示を保存します。
- ヘッダー右側のGitHubアイコンは `https://github.com/wataash/genscale` へのリンクです。
- Settings editor の下のボタンで、現在の設定を含むURLをコピーできます。

## i18n

UIは英語と日本語に対応します。

- `/en`: 英語UI
- `/ja`: 日本語UI
- `/`: 英語UI

言語切り替えはヘッダー右側の `EN` / `JA` リンクで行います。

## キー

キーは半音単位で扱います。内部の基準は `A = 0` で、以降 `A#`, `B`, `C` の順に11まで割り当てます。フラット表記や一部の異名同音も同じ音へ正規化します。

例:

- `Bb` は `A#`
- `Db` は `C#`
- `E#` は `F`
- `Cb` は `B`

## スケールプリセット

スケールプリセットは12個のラベルトークンで構成します。各トークンは、ルートからの半音オフセット順に並びます。

例:

```text
1
...♭9
...9
..♭3
...3
...11
...♯11
.5
...♭13
...13
..♭7
...Δ7
```

現在のアプリには、メジャー、マイナー、ドミナント、ディミニッシュ、ペンタトニック、オルタードなどのプリセットがあります。

画面上のスケール選択では `Altered dominant` や `オルタード` のような正式名を表示します。日本語UIではスケール名も日本語で表示します。内部IDとSVGファイル名には `alt` などの短い識別子を使います。

## 設定エディタ

Settings editor には現在の設定をJSONで表示します。edit の UI 上でキー、スケール、チューニング、Notes、NOTE grayscale を変更するとJSONも更新します。

JSONを編集すると、内容が有効な場合はUIにも反映します。設定JSONは `key`, `tuning`, `notes`, `noteGrayLevels` を持ちます。`scale` は持ちません。

```json
{
  "key": "A",
  "tuning": ["E4", "B3", "G3", "D3", "A2", "E2"],
  "notes": [
    "1",
    "...♭9",
    "...9",
    "..♭3",
    "...3",
    "...11",
    "...♯11",
    ".5",
    "...♭13",
    "...13",
    "..♭7",
    "...Δ7"
  ],
  "noteGrayLevels": [20, 40, 75, 100]
}
```

`tuning` と `notes` は行順と同じ配列で指定します。スケールは `notes` から自動判定され、プリセットに一致しない場合は `Custom` になります。

Settings editor の下にある `Copy URL with this settings (experimental)` ボタンを押すと、現在のJSONを `settings` クエリパラメータに入れたURLをクリップボードへコピーします。URL内のJSONは1行のcompact JSONにし、`{}`, `[]`, `"`, `♭`, `♯` などはできるだけそのまま残します。クエリとして壊れる文字だけ最小限エンコードします。

```text
https://example.com/en?settings={"key":"A","tuning":["E4","B3","G3","D3","A2","E2"],"notes":["1","...♭9","...9","..♭3","...3","...11","...♯11",".5","...♭13","...13","..♭7","...Δ7"],"noteGrayLevels":[20,40,75,100]}
```

このURLにアクセスすると、`settings` のJSONを読み込んで edit の初期設定に反映します。`settings` が無効なJSON、または genscale の設定として不完全なJSONの場合は、デフォルト設定で表示し、Settings editor をエラー状態にします。

concat では、このURLを textarea に 1 行 1 つずつ貼り付けます。

- 初期表示ではサンプルとして 3 本のURLをあらかじめ入れておきます。
- URL は絶対URLでも相対URLでも構いませんが、`settings` クエリパラメータを含む必要があります。
- 有効な行ごとに指板を 1 つ表示します。
- 無効な行がある場合は行番号付きで警告します。
- すべての行が空、または有効なURLが 1 つもない場合は、指板の代わりに空状態メッセージを表示します。

## Notes

Notesテキストエリアで12音のラベルを直接編集できます。

入力ルール:

- 行区切りで12個指定します。
- 並び順はルートからの半音オフセット順です。
- 先頭の `.` の数で丸の濃淡を指定します。
- `TEXT` は黒丸、`.TEXT` は黒に近い丸、`..TEXT` は白に近い丸、`...TEXT` は白丸で表示します。
- 表示時には先頭の `.` はすべて取り除かれます。
- `.`、`..`、`...` のように `.` だけを指定した音は、丸だけを表示してラベル文字は表示しません。

ラベルを省略した例:

```text
1
...
...
♭3
...
...
...
5
...
...
♭7
...
```

12個以外の場合は、画面上に警告を表示し、指板は現在選択中のスケールプリセットで描画します。

## NOTE色

NOTE grayscale では、`NOTE` / `.NOTE` / `..NOTE` / `...NOTE` の4段階それぞれの丸のグレースケールを 0 から 100% で調整できます。

- 各スライダーの左側には、その段階の見本として丸の中に `Δ7` を表示します。
- `Δ7` はプレースホルダーで、実際の Notes 入力内容とは独立です。
- 見本の丸の塗り、枠線、文字色は、その段階の現在のグレースケール設定を反映します。
- 変更した値は指板上の丸表示と Settings JSON の `noteGrayLevels` に反映します。

## Interval 表記

Notesの各行は、ルートからの半音オフセットに対応します。ラベルとして使う interval 表記は自由文字列ですが、プリセットとドキュメントでは次の表記を使います。

| 半音 | 主な表記 |
| ---: | --- |
| 0    | `1`, `R` (Root), `P1` |
| 1    | `m2`, `♭9`, `♯1` |
| 2    | `M2`, `2`, `9` |
| 3    | `m3`, `♭3`, `♯9` |
| 4    | `M3`, `3`, `Δ3` |
| 5    | `4`, `P4`, `11` |
| 6    | `♭5`, `♯4`, `♯11` |
| 7    | `5`, `P5` |
| 8    | `m6`, `♭6`, `♯5`, `♭13` |
| 9    | `6`, `M6`, `13`, `𝄫7` |
| 10   | `7`, `m7`, `♭7`, |
| 11   | `M7`, `Δ7`, `maj7` |

## 指板

- チューニングは1行1弦で指定します。上の行が指板の上側の弦です。
- 初期値は標準ギターチューニング `E4 B3 G3 D3 A2 E2` です。
- チューニングプリセットを選択すると、チューニング入力欄に各弦の音が反映されます。
- プリセットは `ギター`、`ベース`、`5弦ベース`、`6弦ベース`、`7弦ギター` です。
- 行数を増減すると、表示する弦の数も変わります。
- 各行は `E4` や `Bb2` のように音名とオクターブで指定します。
- 表示範囲は0から24フレットです。
- 12フレットと24フレットは太いフレット線で表示します。
- 3/5/7/9/12/15/17/19/21/24フレットは縦長の長方形インレイです。
- 12/24フレットのインレイは他よりやや太く表示します。

インレイの長さは弦の本数に応じて決まります。弦を上から `1弦`, `2弦`, ..., `n弦` とし、弦の間隔を `h` とします。

- `n = 0` または `n = 1` の場合は未定義です。
- `n = 2` の場合は `0.80h` です。
- `n >= 3` の場合は、上端を `1弦` と `2弦` の中間、下端を `(n - 1)弦` と `n弦` の中間にします。

フレット位置は平均律の弦長比から計算します。

```text
L - L / 2^(n/12)
```

この値を0から24フレット表示用に正規化し、SVGのX座標へ変換します。

## SVG書き出し

画面上のSVG要素を文字列化し、Blob URLを使ってブラウザから保存します。ファイル名は現在のキーとスケール、またはカスタムモードに応じて決まります。

例:

- `A-m7.svg`
- `C-M7.svg`

## 実装

アプリ本体は [app/genscale-app.tsx](/home/wsh/d/s/guitar_board/app/genscale-app.tsx) です。状態管理はReactの `useState`、指板の静的データ生成は `useMemo` を使います。サーバーAPIは使わず、すべてブラウザ内で描画します。

スケール定義、チューニング、設定JSON、指板計算などの純粋なロジックは [lib/genscale](/home/wsh/d/s/guitar_board/lib/genscale) に分割します。

- [lib/genscale/scales.ts](/home/wsh/d/s/guitar_board/lib/genscale/scales.ts): スケールプリセット、表示名、Notesとの照合
- [lib/genscale/tuning.ts](/home/wsh/d/s/guitar_board/lib/genscale/tuning.ts): チューニングプリセット、チューニング文字列の解析
- [lib/genscale/notes.ts](/home/wsh/d/s/guitar_board/lib/genscale/notes.ts): 音名、異名同音、Notesラベル、丸の色
- [lib/genscale/settings.ts](/home/wsh/d/s/guitar_board/lib/genscale/settings.ts): Settings editor のJSON読み書き、URL用settings文字列
- [lib/genscale/fretboard.ts](/home/wsh/d/s/guitar_board/lib/genscale/fretboard.ts): フレット位置、指板データ、SVG描画用の寸法定数
- [lib/genscale/i18n.ts](/home/wsh/d/s/guitar_board/lib/genscale/i18n.ts): 英語/日本語UI文言
- [lib/genscale/svg.ts](/home/wsh/d/s/guitar_board/lib/genscale/svg.ts): SVG文字列化
- [lib/genscale/types.ts](/home/wsh/d/s/guitar_board/lib/genscale/types.ts): 共有型
