# genscale 仕様

## 概要

genscale は、ギター指板上にスケールやコードトーンを可視化するWebアプリです。キー、スケールプリセット、チューニングを選ぶと、0から24フレットに各音の機能名を表示します。表示中の指板はSVGとして書き出せます。

## 主な機能

- キー選択
- スケールプリセット選択
- 異名同音のキー対応
- 12音ラベルのカスタム編集
- スケール内音とスケール外音の描き分け
- 24フレット指板のSVG描画
- 表示中SVGのダウンロード

## i18n

UIは英語と日本語に対応します。

- `/en`: 英語UI
- `/ja`: 日本語UI
- `/`: `/en` へリダイレクト

言語切り替えはヘッダー右側の `EN` / `JA` リンクで行います。

## キー

キーは半音単位で扱います。内部の基準は `A = 0` で、以降 `A#`, `B`, `C` の順に11まで割り当てます。フラット表記や一部の異名同音も同じ音へ正規化します。

例:

- `Bb` は `A#`
- `Db` は `C#`
- `E#` は `F`
- `Cb` は `B`

## スケールプリセット

スケールプリセットは12個のラベルトークンで構成します。各トークンは、ルートからの半音オフセット順に並びます。

例:

```text
1
...♭9
...9
♭3
...3
...11
...♯11
5
...♭13
...13
♭7
...Δ7
```

現在のアプリには、メジャー、マイナー、ドミナント、ディミニッシュ、ペンタトニック、オルタードなどのプリセットがあります。

画面上のスケール選択では `Altered` や `オルタード` のような正式名を表示します。日本語UIではスケール名も日本語で表示します。内部IDとSVGファイル名には `alt` などの短い識別子を使います。

## 設定エディタ

Settings editor には現在の設定をJSONで表示します。UI上のキー、スケール、チューニング、Notesを変更するとJSONも更新します。

JSONを編集すると、内容が有効な場合はUIにも反映します。設定JSONは `key`, `tuning`, `notes` を持ちます。`scale` は持ちません。

```json
{
  "key": "A",
  "tuning": ["E4", "B3", "G3", "D3", "A2", "E2"],
  "notes": [
    "1",
    "...♭9",
    "...9",
    "♭3",
    "...3",
    "...11",
    "...♯11",
    "5",
    "...♭13",
    "...13",
    "♭7",
    "...Δ7"
  ]
}
```

`tuning` と `notes` は行順と同じ配列で指定します。スケールは `notes` から自動判定され、プリセットに一致しない場合は `Custom` になります。

## Notes

Notesテキストエリアで12音のラベルを直接編集できます。

入力ルール:

- 行区切りで12個指定します。
- 並び順はルートからの半音オフセット順です。
- 先頭の `.` の数で丸の濃淡を指定します。
- `TEXT` は黒丸、`.TEXT` は黒に近い丸、`..TEXT` は白に近い丸、`...TEXT` は白丸で表示します。
- 表示時には先頭の `.` はすべて取り除かれます。
- `.`、`..`、`...` のように `.` だけを指定した音は、丸だけを表示してラベル文字は表示しません。

ラベルを省略した例:

```text
1
...
...
♭3
...
...
...
5
...
...
♭7
...
```

12個以外の場合は、画面上に警告を表示し、指板は現在選択中のスケールプリセットで描画します。

## Interval 表記

Notesの各行は、ルートからの半音オフセットに対応します。ラベルとして使う interval 表記は自由文字列ですが、プリセットとドキュメントでは次の表記を使います。

| 半音 | 主な表記 |
| ---: | --- |
| 0    | `1`, `R` (Root), `P1` |
| 1    | `m2`, `♭9`, `♯1` |
| 2    | `M2`, `2`, `9` |
| 3    | `m3`, `♭3`, `♯9` |
| 4    | `M3`, `3`, `Δ3` |
| 5    | `4`, `P4`, `11` |
| 6    | `♭5`, `♯4`, `♯11` |
| 7    | `5`, `P5` |
| 8    | `m6`, `♭6`, `♯5`, `♭13` |
| 9    | `6`, `M6`, `13`, `𝄫7` |
| 10   | `7`, `m7`, `♭7`, |
| 11   | `M7`, `Δ7`, `maj7` |

## 指板

- チューニングは1行1弦で指定します。上の行が指板の上側の弦です。
- 初期値は標準ギターチューニング `E4 B3 G3 D3 A2 E2` です。
- チューニングプリセットを選択すると、チューニング入力欄に各弦の音が反映されます。
- プリセットは `ギター`、`ベース`、`5弦ベース`、`6弦ベース`、`7弦ギター` です。
- 行数を増減すると、表示する弦の数も変わります。
- 各行は `E4` や `Bb2` のように音名とオクターブで指定します。
- 表示範囲は0から24フレットです。
- 12フレットと24フレットは太いフレット線で表示します。
- 3/5/7/9/12/15/17/19/21/24フレットは縦長の長方形インレイです。
- 12/24フレットのインレイは他よりやや太く表示します。

インレイの長さは弦の本数に応じて決まります。弦を上から `1弦`, `2弦`, ..., `n弦` とし、弦の間隔を `h` とします。

- `n = 0` または `n = 1` の場合は未定義です。
- `n = 2` の場合は `0.80h` です。
- `n >= 3` の場合は、上端を `1弦` と `2弦` の中間、下端を `(n - 1)弦` と `n弦` の中間にします。

フレット位置は平均律の弦長比から計算します。

```text
L - L / 2^(n/12)
```

この値を0から24フレット表示用に正規化し、SVGのX座標へ変換します。

## SVG書き出し

画面上のSVG要素を文字列化し、Blob URLを使ってブラウザから保存します。ファイル名は現在のキーとスケール、またはカスタムモードに応じて決まります。

例:

- `A-m7.svg`
- `C-M7.svg`

## 実装

アプリ本体は [app/genscale-app.tsx](/home/wsh/d/s/guitar_board/app/genscale-app.tsx) です。状態管理はReactの `useState`、指板の静的データ生成は `useMemo` を使います。サーバーAPIは使わず、すべてブラウザ内で描画します。
